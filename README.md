# Motion Studies: Randomness, Chaos and Complexity

A collection of interactive visualizations exploring fundamental concepts in algorithmic art and computational creativity.

## Overview
This project presents a series of interactive sketches demonstrating various forms of motion, randomness, and emergent patterns using p5.js. Each visualization explores different aspects of algorithmic behavior, from simple random walks to complex particle systems.

## Sketches

### Basic Random Motion
1. **Brownian Motion**
   - Classic random particle movement
   - Demonstrates fundamental random processes
   - Based on molecular collision model

2. **Colorful Brownian**
   - Enhanced Brownian motion with color dynamics
   - Uses HSB color space for smooth transitions
   - Demonstrates velocity-based trail effects

3. **Random Walk**
   - Grid-based random movement
   - Demonstrates discrete vs continuous motion
   - Historical foundation of many algorithms

4. **Interactive Walkers**
   - Multiple particles with interaction forces
   - Mouse-based influence fields
   - Demonstrates emergence through simple rules

### Noise and Fields
5. **Noise Pixels**
   - Direct pixel manipulation
   - Compares random vs Perlin noise
   - Demonstrates coherent noise patterns

6. **Noise Comparison**
   - Side-by-side visualization of noise types
   - Real-time animation of differences
   - Educational comparison tool

7. **Flow Field**
   - Perlin noise-based vector fields
   - Particle systems following flow
   - Natural-looking motion patterns

8. **Field Patterns**
   - Complex field interactions
   - Multiple noise scales
   - Emergent pattern formation

### Complexity and Emergence
9. **Emergence**
   - Self-organizing particle systems
   - Local rules creating global patterns
   - Demonstrates collective behavior

10. **Boids**
    - Classic flocking simulation
    - Based on Craig Reynolds' algorithm
    - Shows emergence through simple rules

### Fractals and Recursion
11. **Recursive Circles**
    - Basic recursive pattern
    - Interactive depth control
    - Demonstrates fundamental recursion
    - Binary subdivision process
    - Clear visualization of recursive depth

12. **Branching Tree**
    - Recursive pattern generation
    - Interactive angle control
    - Natural growth simulation
    - L-system inspired growth
    - Dynamic branch animation

13. **Mandelbrot Set**
    - Famous mathematical fractal
    - Interactive zoom exploration
    - Demonstrates self-similarity
    - Complex number visualization
    - Escape-time algorithm

14. **Julia Set**
    - Related to Mandelbrot set
    - Interactive parameter exploration
    - Complex number visualization
    - Dynamic parameter space
    - Real-time set generation

15. **Sierpinski Triangle**
    - Classic fractal pattern
    - Multiple generation methods
    - Demonstrates recursive subdivision
    - Chaos game implementation
    - Perfect self-similarity

## Technical Implementation
- Built with p5.js
- Interactive controls for each sketch
- Modular design for easy expansion
- Responsive layout

## Controls
- Mouse movement for interaction
- Space bar to pause/play (where applicable)
- 'R' key to reset sketches
- Additional controls noted in each sketch

## Installation
1. Clone the repository
2. Open index.html in a web browser
3. No additional dependencies required
